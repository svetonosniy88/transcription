# WhisperMd v1.0.0

Первый законченный выпуск локального Windows-приложения для транскрибации записей в Markdown.

## Что доступно

- Очередь аудио- и видеофайлов с перетаскиванием и изменением порядка.
- Отдельные заметки, одна общая заметка или заметки по пользовательским группам.
- Контекстная подсказка для распознавания, отображение прогресса и отмена обработки.
- Локальный whisper.cpp на CPU или Vulkan с автоматическим резервным запуском на CPU.
- Библиотека Markdown-заметок, поиск по истории и сохранение настроек.
- Автономный установщик Windows x64 для текущего пользователя.

## Установка

Загрузите `WhisperMd-Setup-1.0.0.exe` из GitHub Release и запустите его. Исходный репозиторий, отдельный .NET runtime и модель для установленного приложения не требуются. Размер установщика: 573 251 830 байт.

SHA-256: `D57D6EAD817746E9E4BA7D4562830BE18E2AC916078F44C659DE9F46174FC331`

Заметки по умолчанию сохраняются в `Документы\WhisperMd`, настройки и история — в `%LOCALAPPDATA%\WhisperMd`. Деинсталлятор оставляет пользовательские данные.

## Проверка

Сборка WPF и установщика, запуск установленного приложения и транскрибация через CPU и Vulkan прошли на Windows. Подробный перечень проверенных и не повторённых на установленной копии сценариев: [release checklist](RELEASE_CHECKLIST_V1.md).

В состав установщика входят сторонние компоненты; сведения о них приведены в [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).
