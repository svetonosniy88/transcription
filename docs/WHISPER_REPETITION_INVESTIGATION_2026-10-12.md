## Почему штатные повторные попытки могли не помочь

В локальном `app/whisper.cpp/src/whisper.cpp` функция `whisper_sequence_score` проверяет разнообразие последних 32 токенов, а не повторение предложений на протяжении записи. Перебор температур срабатывает при неудачном декодировании / низкой уверенности. Ошибочный текст переносится в `prompt_past1` следующего окна.

У повторённой фразы высокая уверенность. Приближённый расчёт разнообразия последних 32 экспортированных токенов на одном участке дал энтропию `2.7996`, выше штатного порога `2.4`. Это вспомогательная оценка по JSON, не запись внутренней телеметрии декодера. Она согласуется с тем, что данный вид повторения проходит мимо штатных критериев.

В контрольном запуске отдельного проблемного фрагмента повторение метки «[звучит музыка]» воспроизвелось **66 раз за 90 секунд** при **нуле temperature fallbacks**. Таким образом, сама настройка дополнительных кандидатов при fallback не гарантирует остановку повторений.

CPU и один из Vulkan-прогонов выполнялись параллельно; их время не использовано для сравнения скорости.

## Что требуется исправить

1. Обнаруживать длительные серии одинаковых или почти одинаковых сегментов по тексту и временным меткам, независимо от оценки уверенности модели. Короткие естественные повторения речи не считать массовым сбоем.
2. При обнаружении серии повторно распознавать соответствующий участок с независимым контекстом. Повторные попытки ограничить; оставшийся сбой явно обозначить пользователю.
3. Проверять результат до создания заметки: массовые повторы не должны проходить как обычная успешная транскрибация. Исходный вывод сохранить для диагностики, а не просто удалить дубликаты из заметки.
4. Рассмотреть ограничение переносимого текста / независимые ограниченные фрагменты и VAD. VAD пока не проверен на этой записи; его эффективность не подтверждена. Постоянное `-mc 0` тоже не является полным исправлением и меняет использование контекстной подсказки.
5. Сохранять диагностический лог с версией движка, фактическим backend, параметрами и количеством fallbacks для будущих разборов.

Эти меры в рамках исследования не внедрены; текущие изменения режимов распознавания остаются без изменения.
